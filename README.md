Az Állat Bála egy .NET MAUI állat listázó alkalmazás. A felhasználó házi illetve haszon állatokat vehet fel névvel, képpel, illetve különböző adatokkal, hogy később ezeket akár meg is lehessen osztani mondjuk egy állatorvossal. Ezeket az adatokat helyi SQLite adatbázisban tárolja (teljes CRUD). Az alkalmazás három oldalból áll: Fő oldal (az állatokat megjelenítő oldal), szerkesztő űrlap és részletező és megosztó nézet. A felépítés MVVM, git verziókezeléssel.
